Why the warnings

The installers are not signed with a paid certificate, so Windows and macOS ask you to confirm the first time.

Which system is tested most

Windows is where the app is developed. The macOS and Linux builds come from the same code and get less testing. If something breaks, tell us.

Updates

On Windows and macOS the app finds new versions by itself and offers to install them. On Linux, download the new file from this page if the app does not offer it.

Older versions and source

Every release and its notes are on GitHub Releases. To build the app yourself, follow the build instructions.
