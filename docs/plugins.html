OpenTrader / Plugins

Plugins

A plugin connects OpenTrader to another application on your computer. A data plugin adds its symbols to your charts; a broker plugin shows your account and trades from the charts. Plugins need the desktop app.

MetaTrader 5Your broker's symbols, account and trading Interactive BrokersAccount, trading, stocks, forex and futures data NinjaTrader 8Futures data, no trading

Install a plugin

  1. Open App settings from the account menu, then Plugins.
  2. Press Browse catalog and install the plugin, then turn it on (Enabled).
  3. Follow its guide above to set up the other application.

The plugin shows Connected once it reaches the other application.

Your symbols

A data plugin's symbols start with its name: MT5:EURUSD, IBKR:AAPL, NT8:ES1!. Find them in the symbol search like any other symbol.

Trading

Trading is off until you turn it on with Trade > Turn trading on. Orders to a live account are confirmed first.

Before you install

  • A plugin runs with your rights on your computer: install only the ones you trust.
  • Catalog plugins are signed by OpenTrader. A plugin installed from a file may not be: the app warns you.
  • Remove a plugin from the same page. It takes back the files it copied.

Write your own

The Plugin API is public, and there is a template to start from.
